# TC04 - Tela de Suporte

## Descrição
Validar que o usuário consegue acessar a tela de suporte e visualizar informações de contato.

## Dados de Entrada
- Usuário logado (ex.: Teste)

## Dados de Saída Esperados
- Tela de suporte exibida corretamente
- Contatos visíveis: email, telefone e celular

## Procedimento de Teste
1. Entrar no aplicativo com usuário cadastrado.
2. Acessar a tela de suporte a partir do menu de navegação.
3. Verificar se a tela carrega corretamente.
4. Conferir se os contatos (email, telefone, celular) estão visíveis e corretos.
