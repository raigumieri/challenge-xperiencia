# TC03 - Acesso aos Cursos

## Descrição
Validar que o usuário consegue visualizar e navegar pelos cursos disponíveis após login.

## Dados de Entrada
- Usuário logado (ex.: João Silva)

## Dados de Saída Esperados
- Exibição da lista de cursos disponíveis
- Navegação pelos capítulos do curso funcionando

## Procedimento de Teste
1. Acessar o aplicativo com usuário cadastrado.
2. Entrar na tela de cursos.
3. Selecionar um curso gratuito disponível.
4. Verificar se os capítulos são exibidos.
5. Testar os botões entre os capítulos.
