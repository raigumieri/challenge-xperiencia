# TC02 - Login de Usuário

## Descrição
Validar que o usuário consegue acessar o aplicativo utilizando um cadastro pré-existente.

## Dados de Entrada
- Email: teste@gmail.com
- Senha: senha123

## Dados de Saída Esperados
- Acesso concedido à tela inicial com cursos disponíveis
- Exibição do nome, email e foto do usuário na barra superior

## Procedimento de Teste
1. Abrir o aplicativo.
2. Preencher o campo "Email" com o email do usuário cadastrado.
3. Preencher o campo "Senha".
4. Clicar no botão "Entrar".
5. Verificar se a tela inicial é exibida.
6. Conferir se o nome, email e foto do usuário aparecem na parte superior.
